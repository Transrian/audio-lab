# 0001 — A published Parakeet model is CC-BY-4.0

- Scope: stt/parakeet-fr
- Derived from: D-006
- Decided by: owner, 2026-11-07

## Decision

If a French Parakeet model from this repository is published, it is released under
CC-BY-4.0. Every other model gets its own license decision.

## Why

The base model (NVIDIA Parakeet TDT 0.6B v3) is CC-BY-4.0, and so are the Granary
transcripts used for training. A derived model cannot be released under looser
terms. Training data with a non-commercial license (for example CC-BY-NC) is
therefore excluded from any model meant for publication.

## Alternatives considered

None discussed.
